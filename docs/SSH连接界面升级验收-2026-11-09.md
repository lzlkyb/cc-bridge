# SSH 连接界面升级验收

按已确认的《SSH连接与新建交互设计稿-2026-11-09.html》实施，未修改应用版本，未构建或安装 EXE。

## 正式界面

- 共享侧栏采用名称、主机、用户名分层；状态带文字说明，会话数量带单位。点击在线项优先回到上次使用的普通终端，多终端可展开选择；分屏副格不作为普通标签暴露。
- 搜索支持名称、主机与用户，提供清空与空状态入口；菜单补充复制地址。连接发起失败显示原因、重试和编辑，多个服务器并发连接分别保持忙状态。
- 删除保留现有实际行为：删除配置会断开相关会话并关闭终端；行内确认如实提示影响，而不是沿用设计稿中保留标签的模拟行为。
- V2 新建、编辑共用 800px 双栏表单：左侧连接信息与常驻跳板机，右侧认证与连接路径。常规桌面密码、密钥高度均约 566px，短窗口进一步收紧间距，800×650 与 1000×650 无内部滚动；极窄、极矮窗口保留滚动兜底以保证可达性。兼容浅色、深色、玻璃、经典实色与减少动态效果。
- 侧栏主机 14px、用户名与会话入口 13px、名称 15px、状态 12px；更多图标 18px、点击区域 32px。连接栏宽度按窗口取 280–300px，用户名与会话入口分行，单会话直接切换、多终端展开。玻璃表面为乳白与烟灰材质，输入框及跳板机控件保持同一层级。
- 提交时内联校验名称、主机、用户、端口、私钥路径，并聚焦首个错误。保存失败保留字段；同帧连点只提交一次，保存中不可误关。新建草稿仅留内存，关闭可恢复，取消或保存后清除。

## 保存并连接与凭据边界

使用 `ssh_save_connection` 返回的连接 ID 发起新终端，避免新建 ID 或编辑后的目标被旧查询结果替代。

未记住的密码、密码短语通过本次 `ssh_connect` 的可选参数传入现有 PTY 自动认证派发器，消费一次即移除。不会写入连接配置、React Query、终端会话对象或恢复快照；重连不复用一次性凭据。跳板凭据仍从跳板机自身配置读取。旧版不带凭据的调用保持兼容。

保留已保存凭据的本机按需查看；解密请求在关闭、切换认证或输入新值后失效，迟到结果不得覆盖新输入。
