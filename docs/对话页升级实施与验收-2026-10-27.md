# 对话页升级实施与验收

日期：2026-10-27。状态：已落入生产源码，完成本记录列明的前端验证；未打包发布或安装验收。

用户确认交互设计稿后授权实施。本次以日常聊天效率为主，沿用 `desktop/src/appearance.css`、`desktop/src/index.css` 的应用外观体系，保留既有会话生命周期与后端协议。原[升级方案](对话页全面升级方案-2026-10-27.md)和[交互稿说明](../design/chat-workspace-2026-10-27/brief.md)保留为历史设计依据；本记录描述当前交付。

## 已实现的使用体验

| 场景 | 当前行为 |
|---|---|
| 进入与切换会话 | 列表和正文共享工作区框架；顶栏先显示当前标题，再显示环境与目录。列表展开时搜索与“新对话”常驻；保留最近/已归档入口、分叉关系、宽度调整和每会话草稿。工作区可用宽度小于 900px 时列表改为抽屉。 |
| 阅读与查找 | 默认正文 15px / 1.75 行高，阅读选项提供 14 / 15 / 16px 和执行过程详略；宽屏限制正文及输入区宽度。会话内搜索有可见入口，命中已折叠工具时展开内容。回看旧消息不因新回复强制跳到底部。 |
| 理解执行过程 | 可合并的连续成功工具调用显示“已完成…项操作”，可展开细节；运行、失败、审批及提问保留各自内容。输入上方可跳到待审批操作，继续沿用审批与 Diff 能力。 |
| 准备下一条消息 | 模型和执行模式移到输入旁；历史回复保留当时的模型标识。图片、@ 引用和命令有可见入口；紧凑宽度用“更多输入操作”保留命令和润色。发送快捷键有明确设置，保留中文输入法保护及附件状态校验。 |
| 润色草稿 | 先展示候选稿，采用后才替换正文；取消保留原稿。润色期间继续编辑会使旧结果失效，避免覆盖新内容。 |
| 连续提问与停止 | 队列显示下一条预览，可展开、按条编辑文字、移除或清空；编辑保留原附件。停止本轮同时暂停队列，内容保留，需点“继续发送”恢复。队列操作使用稳定标识，过期编辑不会误改下一条。 |
| 故障恢复与低频操作 | 错误摘要、传入的错误详情与最近诊断合并展示；环境不可用时提供“重新检查环境”“检查连接配置”。会话信息、导出、改动、终端和“从本机历史打开”收进有文字的菜单。编辑消息明确为“编辑并新开会话”，普通再次提问为“再问一次”。 |
| 窄窗与键盘 | 弹层脱离滚动容器，限制在视口内；支持 Escape 与焦点返回，抽屉子菜单关闭后保留列表。紧凑窗口保持发送/停止可达；支持柔光、经典两种外观的深浅主题。 |

## 与原方案的差异及验证边界

- 会话搜索常驻，但当前列表仍按既有目标分组、保留排序及打开/存储会话结构，未改成全面按最近活动排序的统一来源列表。本机 CLI 历史仍通过专门入口打开；没有跨会话正文全文索引。
- 工具摘要合并符合条件的连续成功调用，不是新的全轮执行报告。错误卡合并当前传入的诊断，保留最近 stderr 的既有取数边界；未引入跨来源、按尝试标识关联的完整错误治理机制。
- 输入区已增高并支持内部滚动，未新增独立长文展开编辑器。队列编辑支持文字与原附件保留，不新增队列内替换附件功能。文件引用沿用 @ 能力，不代表任意格式文件上传；历史缩略图不代表原图可带入新会话。
- 模拟长会话包含 500 余条消息，已验证回看与底部跟随行为；未建立输入延迟、帧率或内存的量化性能基线。150% Windows 系统缩放、真实桌面 WebView、真实 SSH/模型、完整辅助技术与对比度测量未在本次浏览器报告中验收。
- 未重做全局品牌、终端或连接页，未增加云同步或团队协作，未更改授权策略、消息协议或承诺分叉回滚文件。未执行 Tauri 安装包发布、升级或安装验证。

## 复现预览与检查

在仓库根目录打开 PowerShell，使用已安装的 Node.js/npm；首次准备工作区时先安装 `desktop` 依赖。预览只使用本地模拟数据：

```powershell
Set-Location D:/AItool/winapp/cc-bridge/desktop
npm ci
npm run vite:dev -- --host 127.0.0.1 --port 1437
```

打开 [生产组件预览](http://127.0.0.1:1437/e2e/chat-workspace.html)。可加 `?scene=approval`、`?scene=error`、`?scene=empty` 或 `?scene=long`；`theme=dark`、`material=classic` 可组合查看外观。

浏览器验证脚本使用 Microsoft Edge 和 `design/chat-workspace-2026-10-27/.qa/node_modules` 中的 Playwright。新检出缺少该隔离依赖时，在仓库根目录运行 `npm install --prefix design/chat-workspace-2026-10-27/.qa --no-save --package-lock=false playwright`。保持预览服务运行，在另一个终端执行：

```powershell
Set-Location D:/AItool/winapp/cc-bridge/desktop
node scripts/verify-chat-workspace.mjs
npm test
npm test -- src/components/ccgui/Composer.test.tsx src/components/ccgui/ChatWorkspace.test.tsx src/components/ccgui/ccguiUx.test.tsx src/hooks/useCcSession.test.tsx
npm run lint
node scripts/check-component-size.mjs
npm run vite:build
```

浏览器脚本会覆盖 `.impeccable/review/chat-production/report.json` 及同名截图；需保留旧证据时先另存。以上命令分别用于复现全量与最终相关测试，无需把两次测试数量相加。
