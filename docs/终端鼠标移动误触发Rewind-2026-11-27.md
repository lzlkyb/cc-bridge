# 终端移动鼠标误进 Rewind（2026-11-27）

用户在远端 Claude Code 中移动鼠标时，界面偶发跳到 Rewind。cc bridge 原先会把每条 SGR 鼠标移动报告分别通过 IPC 写给远端，密集移动会产生大量写入。部分序列被远端当作 Esc 处理是待验证的解释，现有记录无法确认 Rewind 的根因。

## 改动

- 每个 SSH 会话独立合并高频移动报告。保留窗口内最后一个位置并去除重复报告，合并窗口为 40 毫秒。
- 点击、抬起、滚轮和普通输入按原样发送。若还有待发移动报告，它会与下一条非移动输入放在同一次写入中，确保两者的字节顺序。
- 点击或输入后重新开始坐标去重，防止下一次交互同位置的移动被吞掉。关闭终端时取消待发报告。

## 验收

- 自动测试覆盖 SGR 解析、拖动、抬起、滚轮、同位置点击后移动、输入写入顺序和关窗取消。
- 仍需在实际 Claude Code SSH 会话中快速移动鼠标 30 秒，观察是否出现 Rewind，并核对点击、拖动和滚轮。
