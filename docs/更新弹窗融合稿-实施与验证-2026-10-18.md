# 更新弹窗融合稿实施与验证

采用已确认的 `design/2026-10-18-update-dialog-fusion.html`：540px 原生面板、版本升级概览、跨版本精选亮点、按需展开的本次及跨版本记录，底部按钮固定。深浅主题沿用应用 token。

## 数据与兼容

- `CHANGELOG.md` 是唯一手写来源；`### 亮点` 中使用 `**标题**：描述`，已有生成器会同步到应用历史。每个版本优先选一条，去重后最多显示四条。
- 发布脚本在原有 `notes` 后附加单行 HTML 注释元数据，携带最近十个已发布版本。沿用现有 updater 通道，无额外请求；更新下载、稍后记忆和 8 秒可取消重启流程保持原样。
- 只聚合 `当前版本 < 记录版本 <= 目标版本` 的已收录内容。无法确认当前版本时仅展示本次说明；缺少完整历史时不声称覆盖全部版本。
- 旧更新源的分类说明、纯文字和空说明均可显示。旧说明渲染器忽略单行元数据。HTML 内容由 React 按文本渲染。
- 发布后更新源才会携带新增元数据；当前线上清单不会被本地修改自动改变。

## 动效与性能

- 使用共享 `Modal`，180ms 进入、140ms 退出，仅 opacity/transform；移除该弹窗对旧光晕和重复入场样式的使用。
- 正文不逐条延迟入场，完整记录在展开时挂载；折叠箭头沿用 160ms 反馈。遵循系统减少动态效果设置。
- 高度限制为视窗内可用空间；版本概览、亮点和记录共用内部滚动区，标题和操作区固定。
