# 小队与输入框升级实施与验收

已将确认的小队与输入框设计接入正式 React 对话页面，沿用原有 Tauri 会话、任务事件和发送链路。

## 页面与布局

- 小队默认展示全部成员，不需要点击展开。成员多时在小队区域内滚动，成员位置保持稳定。
- 以对话面板实际宽度为断点：1100px 以上常驻右侧 280px 协作栏；其他窗口在输入框上方横向浏览成员。正文、成员区、输入框分别占有明确布局区域，成员详情不覆盖输入框。
- 小队通过布局槽位显示，业务状态仍由原工作区持有；关闭成员详情或查看执行记录不会隐藏小队，也不会丢失停止中的反馈。
- 使用真实 Agent 名称和角色信息，辅以稳定编号。配色由 taskId 决定，工具切换不会改变身份；没有明确角色时显示“小队成员”，不根据任务描述猜角色。

## 角色与动作

- 六组柔和配色，探索围巾、实现袖口、审查眼镜、验证标记，继续使用原有圆润矢量角色。
- 读取、编辑、搜索与命令动作跟随任务状态。最多两位活跃成员保持完整工作动作，其余以低幅度动作呈现；动作相位按成员身份错开。
- 成员实时完成播放一次反馈，历史恢复保持静态。输入、选中文字、隐藏会话、应用减少动态和系统减少动态均有对应限制。
- 单成员停止继续调用已实现的后端 stop_task 链路，不以动画或按钮状态代替真实终态确认。

## 输入区

- 18px 圆角复合输入面，统一聚焦边界和轻度阴影，兼容经典/玻璃和深浅主题。
- 文件引用、命令操作直接可达；添加菜单保留图片和草稿润色。模型与权限在窄窗口独立排列。
- 窄窗口保留发送方式文字，避免“发送”和“排队发送”只剩相同箭头。中文输入法、草稿、附件和停止后发送仍沿用既有实现。
- 矮窗口依据 CSS 约束自动调整草稿高度上限，减轻输入区对正文的挤压。

## 验收

- 全量前端：161 个测试文件、1605 项测试通过。
- 对话浏览器回归：25 项通过，包含审批、中文输入法、附件、队列、草稿、搜索、模型和阅读位置。
- Clawd 状态回归：9 项通过；单成员停止：1280、800、390 三种宽度通过。
- 新布局：1800×1000、1280×840、800×600、560×700、390×700 五组通过，覆盖经典/玻璃及深浅主题。验证八名成员默认存在、身份差异、右栏/横条切换、停止操作可见、输入时安静、减少动态、引用、命令与排队发送。
- 生产前端构建、类型、ESLint、组件体量、差异空白检查通过。

证据：`.impeccable/review/squad-composer/`，验收脚本 `desktop/scripts/verify-squad-composer.mjs`。
