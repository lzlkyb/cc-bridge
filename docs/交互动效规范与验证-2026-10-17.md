# 交互动效规范与验证

范围：在既有 UI 上统一反馈和动效，不更换布局、视觉主题、业务接口、SSH 会话或轮询机制。不新增运行时依赖。

## 设计依据

- [Apple HIG · Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：反馈简短且准确，避免高频操作反复播放多余动画，尽可能支持取消与中断。
- [Apple · Reduced Motion evaluation criteria](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/reduced-motion-evaluation-criteria)：尊重系统偏好，以静态状态、文字或轻量反馈保留含义。
- [Linear · Improvements and fixes](https://linear.app/changelog/page/5)：更直接的悬停反馈及操作连续性。以下时长是本项目实施值，不是 Apple 或 Linear 公布的硬性参数。

## 动效约定

| 场景 | 时长 | 表现 |
| --- | --- | --- |
| 按压 | 70ms | 按钮下移 1px；开关拇指轻微压缩，松开恢复 |
| 悬停、颜色反馈 | 100ms | 背景、边框与文字响应，禁用态不产生按压反馈 |
| 列表状态变化 | 160ms | 使用既有 FLIP，不重挂页面 |
| 页面切换 | 200ms 入场 / 100ms 退场 | 内容区快照上移 6px 入场、旧画面上移 3px 淡出，交叉衔接；页面保留 DOM、表单和滚动位置 |
| 弹层进入、保存确认 | 180ms | 弹层淡入，最多位移 4px、缩放 .985 → 1 |
| 弹层退出 | 140ms | 先退出再移除；快速重新打开会取消旧卸载任务 |
| 主题切换 | 320ms | 有界颜色过渡，重复切换后也会清理标记 |

进入使用 `cubic-bezier(.16,1,.3,1)`，退出使用 `cubic-bezier(.4,0,1,1)`。沿用现有 z-index 与门户层级。时长分别存于 `index.css` 的 token 和 `lib/motion.ts`，浏览器测试校验两者一致。

页面切换使用 [View Transitions API](https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition) 捕获内容区画面，仅在快照层动画，不给真实页面添加 transform。顶栏、侧栏、通知继续实时响应，动画层不截获点击。连续切换跳过上一段动画，并用请求序号废弃旧回调，避免最后一次选择被覆盖；点击当前页不重播。

不支持快照的旧环境保留 200ms 的 CSS 轻移入场，每次返回保活页都会重播；旧环境终端采用可感知的淡入，保护全屏与固定菜单坐标。系统减少动态效果或窗口隐藏时不创建快照。折叠继续使用原来的 grid 槽位，不修改终端尺寸与会话生命周期。

## 反馈与可访问性

- 加载按钮保持原宽度，含调用方在 busy 时移除原内容的情况；保留原 gap，提供 `aria-busy` 和状态文案，阻止重复操作。
- 通知继续驻留 3.5 秒，悬停、内部焦点或窗口隐藏时暂停 JS 计时和进度条。自动关闭与手动关闭共用退场，错误使用 `role=alert`，一般反馈使用 `role=status`。进度条改用 transform，不逐帧改变宽度。
- 通知堆叠的 FLIP 作用于外层槽位，通知自身的进退场作用于内层，避免争用 transform。
- 菜单退出立即 inert；Esc 归还触发器焦点，并阻止事件穿透外层弹窗。菜单项支持方向键、Home 与 End。
- 命令面板共用弹层动效及关闭计时，限制退出/异步处理中重复执行，补齐焦点循环和焦点归还。
- 保存提示以状态区域播报。数字滚动自身也读取系统减少动态效果偏好，不依赖调用方传参。
- 减少动态效果时：取消弹层、通知与按压位移，JS 关闭不等待动画；隐藏倒计时装饰，保留文字、图标、颜色和忙碌语义。

## 预览与验证

`design/2026-10-17-motion.html` 是可离线打开的真实组件预览，使用示例操作，不调用 IPC。开发入口为 `desktop/motion-preview.html`，不进入正式应用入口。

在 `desktop/` 执行：

```powershell
npm run vite:dev -- --host 127.0.0.1 --port 1425
# 另一个终端；Playwright 需可通过 node_modules 或 NODE_PATH 解析。
node --test scripts/check-motion.mjs
npm test
npm run lint
node scripts/check-component-size.mjs
npm run vite:build
```

浏览器回归使用本机 Edge（Windows）或 Playwright Chromium；可用 `MOTION_BROWSER_PATH` 指定浏览器、`MOTION_PREVIEW_URL` 指定离线预览或测试服务器、`MOTION_ARTIFACT_DIR` 指定截图目录。本次使用 Node 24 和内置工作区运行时中的 Playwright，无需修改项目依赖。

回归覆盖：加载几何稳定、弹层进出场及快速反转、退出菜单 inert 与嵌套 Esc、通知手动/自动关闭及悬停/聚焦暂停、开关按压不越界、保活页面的草稿/滚动/DOM 身份、系统减少动态效果与实时切换、主题清理及 1200px/560px 深浅主题无横向溢出。

验证范围为前端单元测试、真实组件浏览器回归、生产前端构建和深浅主题截图。未构建安装包，未将预览操作连接真实 SSH 或系统设置。

### 本次结果

- 单元测试：50 个文件、663 项通过。
- 固定生产预览的真实浏览器回归：10 项全部通过，无预览运行时错误；新增真实动画关键帧、快速点击回原页、旧环境重复入场验证。
- ESLint、组件体量门禁、`git diff --check` 和 TypeScript/Vite 生产前端构建通过。
- 正式页面的命令面板打开、Esc 关闭及触发器焦点归还通过浏览器检查；真实 Tauri/SSH 行为不在浏览器预览验证范围。
- 正式页面的连接、终端、安全、日志导航均通过浏览器切换检查：每次仅一个内容页可见，四次快照均进入可播放状态，真实页面 transform 均为 none。
- 机械设计检查仅报告原有侧栏标签的 `max-width` 过渡警告，该处未因本次改动调整。

### 切页性能采样

本机 Edge 155、1200×800、独立组件预览连续切换 12 次，使用 CDP Performance 计数与 requestAnimationFrame 采样：150 个帧间隔，P95 为 16.8ms，最大 16.9ms；捕获到可播放状态的 P95 为 26.4ms。该数据来自本机预览，不代表真实 SSH 负载或所有设备性能。

实现仅在导航时创建短时快照，不新增常驻 RAF、轮询、模糊或宽高逐帧动画；结束后快照由浏览器回收。浏览器回归同时断言过渡完成后无残留的切页动画、真实页面 transform 为 none、转场中可输入。
