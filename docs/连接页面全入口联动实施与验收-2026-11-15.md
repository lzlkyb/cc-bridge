# 连接页面全入口联动实施与验收

日期：2026-11-15。应用版本：3.1.5。

状态：正式代码、自动回归、正式组件验收及原生开发窗口确认已完成。

## 实施结果

沿用已确认的页面和卡片布局，覆盖连接页、顶栏、侧栏异常入口、托盘、命令面板与终端全屏。接入方式仍为「隧道连接〔推荐〕」和「IP 直连」，IP 直连保留原有手动流程。

- 后台提供同一份当前接入摘要，包括方式、服务器、固定地址或本机地址、原条目、范围、项目目录、通道状态及可执行操作。各入口使用同一份摘要，切换目标期间不继承旧目标的证据和复制反馈。
- 原「接入 Claude Code」卡片常驻地址摘要和复制入口。隧道初次未配置时不显示直连替代地址或命令；VPN 恢复继续使用固定地址，不提示更换 IP。
- 本机服务、隧道或直连地址检查、客户端验证分别表达。接入检查可以核实远端配置和固定地址；本机探针、累计请求与复制成功都不代表当前服务器或项目中的 Claude Code 已加载配置。客户端继续显示待验证，引导用户重新打开 Claude Code 并查看 `/mcp`。
- 地址及命令复制统一由后台解析当前保存的目标，保留条目名称、HTTP/HTTPS、HTTP/SSE、端口、范围和项目目录。生成或写入剪贴板期间切换目标时取消旧反馈；剪贴板写入成功后才保存命令收据，收据只记录复制时的参数。
- 直连地址和 Token 更新使用原条目、原配置位置和原范围；修改前检查配置内容，保留其他条目、请求头和选项。复制更新命令不会认定服务器已经应用。
- Token 从任意入口重生成后，受影响的已保存接入提示待应用；成功应用后跟随统一状态收起提示。切换服务器后不显示旧目标迟到的成功反馈。
- 本机启停、重启和配置导入共用操作锁。界面共用进行中及失败状态，多个入口不能同时提交同一启停操作；停止或重新启动本机服务不会恢复用户主动暂停的隧道。
- 顶栏、托盘和命令面板的接入入口定位到原卡片，并移动键盘焦点。托盘导航请求保存在应用状态，前端监听建立后读取，支持窗口重新创建后的定位。
- 保留项目级推荐、项目级与全局互切、原名称及固定端口；保留专用隧道与手动端口转发的隔离。

## 原生开发窗口

正式 Tauri dev 已重新编译并启动，窗口使用当前工作区代码，版本为 3.1.5。通过原生窗口读取确认：本机服务运行中，当前保存的隧道显示已连通，顶栏、主卡和原接入卡使用一致的接入方式、项目范围与客户端待验证状态。

## 实机边界

浏览器中的 SSH、网络恢复和配置读写由隔离数据模拟；Python 检查使用临时配置文件。它们验证界面接线、固定地址和原条目更新规则，不等同于完整的真实服务器接入流程。原生窗口已确认当前隧道状态；真实 VPN 断线恢复、服务器配置迁移及 Claude Code 客户端加载仍需实机验证。
