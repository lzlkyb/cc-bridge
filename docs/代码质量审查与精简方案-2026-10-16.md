## 3. 批次 1：前端公共抽象（低风险、高收益）

### 1.1 `createPreferenceStore<T>()` —— 消掉 9 份 localStorage 三件套 ⭐最高性价比

**证据**（`grep -ln "listeners.add\|listeners.forEach" lib/*.ts` 命中 9 个文件）：

`terminalFontSize.ts:21-58`、`terminalScrollback.ts:28-67`、`terminalScrollSpeed.ts:14-45`、`terminalAppearance.ts:52-100`、`terminalPreset.ts:110-173`（**一个文件里 3 份**）、`terminalTuiGuide.ts:26-78`、`terminalSessionRestore.ts:23-42`、`windowState.ts:33-54`、`uploadDir.ts:58-68`。

九处结构完全同构：

```ts
export function loadScrollback(): number { if (cache !== null) return cache; cache = DEFAULT; try { ... } catch {} return cache; }
export function subscribeScrollback(fn) { listeners.add(fn); return () => listeners.delete(fn); }
export function saveScrollback(n) { const v = clamp(n); cache = v; try { localStorage.setItem(KEY, String(v)); } catch {} listeners.forEach(fn => fn(v)); }
```

**改法**：新建 `lib/preferenceStore.ts`，导出
`createPreferenceStore<T>({ key, default, parse, serialize })` → `{ load, save, subscribe, set, resetForTest }`。
各模块**只保留自己的 `parse` / 夹取范围 / 默认值**（这些是业务语义，必须原样搬进去），样板收缩到 ~10 行。

**安全网**：9 个模块里 7 个已有 `.test.ts`（`terminalScrollback` / `terminalScrollSpeed` / `terminalFontFamily` / `terminalAppearance` / `terminalTuiGuide` / `windowState` / `uploadDir`）。**先跑绿 → 再改 → 必须仍绿**。

**收益**：约 −200 行，且消除「9 份各自实现的迁移/夹取逻辑」这个长期隐患。

### 2.3 `backup_before_write()` —— 备份+prune+审计 7 处 ⭐

**证据**（`grep -rn "backup_before_overwrite\|record_op_backup" mcp/tools/*.rs`）：`write_files.rs:127`、`edit_files.rs:285`、`delete_files.rs:62`、`copy_files.rs:74`、`move_files.rs:106`、`notebook_edit.rs:117`、`remove_directory.rs:72`。

七处都是同一段：

```rust
if resolved.exists() && config.backup_enabled {
    let db = state.db.lock().await;
    let bp = backup::backup_before_overwrite(&resolved, &config.backup_dir, &state.data_dir, &db)?;
    backup::prune_backups(&resolved, &config.backup_dir, &state.data_dir, config.backup_retention, &db)?;
    drop(db);
    crate::audit::record_op_backup(bp, Some(resolved.clone()));
}
```

**🔴 这是备份/审计安全链**：抽象时 `drop(db)` 的时机与 `record_op_backup` 的**必调性**不能变。漏掉 = 死锁或审计断链。

1. **不引入 `anyhow` / `thiserror`**。`registry.rs:27` 的 `ToolRunner` 签名固定为 `Result<Value, String>`，工具层约定就是 `Result<T, String>`；引入会造成全仓 churn 且与签名冲突。最多加 `type ToolResult<T> = Result<T, String>` 别名，收益有限 → 不做。
2. **不动终端协议的运行时行为**：`terminalInputHold` / `terminalSelectGesture` / `terminalContextMenu` / `terminalScroll` / `terminalSttyDance` / `useSshTerminalSelect` / `SshTerminal` / `useSshTerminalSession`。这些是四~六轮实测修复的高风险区，本方案对它们只提「重复 JSX / 类型命名」层面的意见，且方向都是**让它们变小**。
3. **不抽象安全代码的语义**：白名单校验、扩展名/大小/越界检查、审计落盘、备份与一键回滚、401 熔断（`security/ban.rs`）、readonly 门禁（`http.rs:807-823`）—— 宁可重复，也不把语义藏进 helper。涉及安全链的抽取（2.3 / 2.5）必须逐字保留原语义。
4. **不做「弹窗让用户点确认」类功能**（R17）。
5. **不改已贴 300 行棘轮线的 4 个文件**（只能变小）：`TerminalTab.tsx`(299)、`SshTerminal.tsx`(296)、`useSshTerminalSelect.ts`(299)、`TerminalPanes.tsx`(275)。
6. **不牵动 MCP 三件套流程**：本方案不新增/删除任何工具，`mcp/tools/*.rs → mod.rs → registry.rs` 与 README 工具表均不变。
