# 设置页面全面审查与升级方案

日期：2026-10-21。基线：提交 `39256cc`；本轮只审查和提出方案，不改动程序代码。

## 1. 结论与改造目标

建议围绕“按类别完成任务、核心操作可见、保存结果可信、危险操作明确确认”升级设置中心。保留经典与柔光两种材质、应用和终端明暗独立、`设置 → 应用 → 外观` 入口及已有高风险确认。

优先级依次为：操作安全与反馈正确性 → 分类和导航 → 控件与视觉统一 → 即时预览和细节完善。视觉升级不应扩大权限、改变安全默认值或建立第二套配置来源。

目标：

1. 用户能从分类名称判断设置归属，主要设置不再隐藏在长页面或泛化的“高级”中。
2. 同一类选择、输入和操作遵循同一控件规范，同时保留主次区别。
3. 界面明确区分“已选择”“保存中”“已保存”“已生效”“下次连接生效”。
4. 用户在改变网络、授权或数据保留策略前能理解影响。
5. 经典/柔光 × 浅色/深色下，布局和操作保持一致。

## 2. 审查范围与证据边界

- 阅读设置导航、13 个 Windows 分区，以及外观、终端、备份审计、网络、安全、外挂 MCP、通知、配置迁移等实际源码。
- 使用本地真实 React 组件与示例后端核对柔光深浅色、搜索、1440px 和 560px 窗口；没有操作真实服务器或执行清理、授权、导入和重启。
- 当前示例状态中，设置容器可视高度约 904px，滚动内容约 6985px；关于区约 2127px、终端区约 1046px。数值随展开状态、窗口和数据改变，不能视为固定页面尺寸。
- 常用选项胶囊实测字号 11.5px、高度约 26.9px。问题主要是可读性和层级，不据此直接判定违反最小点击目标要求。
- “字号”检索命中“终端风格与状态栏”，定位到整张终端卡，未直接定位字号控件。
- 560px 示例窗口未发现设置行横向溢出；仍需覆盖 HTTPS 展开、有多个 MCP 服务、长路径、错误文本及系统缩放。
- Impeccable 对所审设置源码和共享控件的静态规则扫描返回空结果。这不能替代交互、语义、信息架构或完整无障碍检查。
- 未完成真实屏幕阅读器测试、全部透明背景合成对比度测量、macOS 真机验证和性能基准，不宣称全面合规。

## 4. 已确认的问题与优先级

本方案的 P0 表示应优先保护用户数据的产品问题；不是对整个软件进行安全等级认定。

| 优先级 | 已确认问题 | 影响与建议 |
|---|---|---|
| P0 | 审计保留天数输入后 800ms 或失焦即保存；后端收到该字段后立即后台清理 | 输入数字就是潜在删除动作。改为草稿输入和“应用保留策略”；缩短保留期前说明删除范围，条件允许时计算影响条数，保留“永久保留”显式选项 |
| P1 | `useSettingSave` 捕获错误但不向调用方报告失败；HTTPS 调用后仍会继续重启和提示成功 | 保存失败与实际运行状态可能矛盾。保存返回明确结果或抛错，失败即停止后续步骤；分开显示保存失败和重启失败 |
| P1 | SSE 确认后直接调用异步保存入口，随后立即提示已切换 | 成功提示早于实际结果。等待服务端确认后再显示成功，保留失败状态和迁移指引 |
| P1 | 共享保存 hook 无行级 pending 状态；每卡仅一个 `savedKey` | 快速连续操作可能覆盖反馈，缺少明确的进行中状态。按设置键管理状态，并避免过期请求结果覆盖最新选择 |
| P1 | 开机自启读取失败后，以默认 false 结束加载；终端偏好存储失败可能仍显示已保存 | “未知”容易被误认为“关闭”，“本次生效”容易被误认为“已持久保存”。增加读取失败重试，明确本次生效但未记住的情况 |
| P1 | 审计保留天数、自定义清理天数输入缺少关联标签；TLS 条件区数字输入也使用分离的文本标签 | 可见标签与读屏名称未统一。为共享行、输入、说明和错误建立唯一 id 关联 |
| P1 | 13 个分区全部连续渲染，分类导航实际是长页面滚动定位 | 关于、更新历史、统计和设置竞争空间。改为当前分类内容页，保留状态和旧锚点导航兼容 |
| P1 | 高级混合限流、编码、MCP 命令持久化、界面内存、SSH 拖选与复制 | 用户需要记住开发实现位置。将选项归到实际任务领域；MCP `run_command` 的会话持久化不能误归为 SSH 会话保持 |
| P2 | 大量单选均使用小胶囊；协议按钮、字体卡、外观选项的选中表达不同 | 控件功能与重要程度不易区分。有限单选用分段器，视觉选项用预览卡，长列表用下拉，动作使用按钮 |
| P2 | 宽卡片内短标签与右侧开关距离过大，部分选项堆在左上角 | 扫视关联弱、空间利用不均。统一阅读区宽度和控制列，宽屏多余空间用于预览或上下文说明 |
| P2 | 设置搜索可以匹配关键词，但多个控件共享卡片级搜索入口；搜索结果分组存在“其它”等旧称 | 找到卡片后仍需二次寻找。精确索引到控件，显示当前分类路径、当前值和生效方式 |
| P2 | 导航区域滚轮到边缘后会切换分区 | 普通滚动可能变成导航跳转。取消这种默认行为，分类通过点击或明确键盘操作切换 |
| P2 | 字体有静态示例，应用材质和终端配色仍主要靠名称选择 | 无法在设置位置可靠比较效果。提供真实组件材质缩略图与独立终端示例，不连接真实 SSH 来做预览 |
| P2 | 备份设置和管理分散，配置导入提示“全部配置”，但终端等偏好存储在本地 | 去向和覆盖范围不清楚。区分“策略设置”和“查看/还原历史”，明确当前导入导出的覆盖范围和凭据影响 |

## 5. 信息架构：7 个日常分类与独立关于入口

关于可以保留现有固定入口，但不再让长更新历史占据默认设置内容。首次进入建议打开应用；之后记住上次分类及滚动位置。每次只呈现当前分类，避免再次把所有分类默认展开。

| 分类 | 子分组与设置内容 | 来源与处理 |
|---|---|---|
| 应用 | 外观：经典/柔光、浅色/深色；启动与资源：开机自启、关窗释放界面内存；安装与引导：安装目录、桌面快捷方式、重新查看引导 | 保留 `设置 → 应用 → 外观`；合并应用、安装及资源偏好 |
| 终端 | 外观：终端明暗、配色、字体、字号；操作：拖拽即选、选中即复制、TUI 滚动速度；历史与集成：回滚缓冲、路径/分支探测、tmux 桥接 | 归并 SSH 相关操作；按外观/操作/集成拆段，高级解释按需查看 |
| 网络与接入 | 服务监听：端口、HTTP/SSE；HTTPS：证书、地址、封禁策略；防火墙：状态、修复和手动命令；流量保护：限流及关联参数 | 网络、防火墙、TLS、限流形成一条完整接入任务链；平台不支持的项不展示可点击假入口 |
| 文件与命令 | 文件读取兼容：编码自适应；MCP 命令行为：壳层、工作目录/环境持久化；访问策略：当前白名单、只读、命令执行状态及管理入口 | 基础策略入口与安全工作区保持单一配置来源；不能把 MCP 命令会话与 SSH 会话混称 |
| 外挂 MCP | 桥总开关、服务列表、单服务启停、工具暴露范围、远端工作目录规则、导入/添加 | 列表摘要常驻，编辑与复杂配置按需进入；保留已有总开关/服务/工具范围的生效说明和扩权确认 |
| 数据与记录 | 备份策略与管理入口；审计记录与保留策略；用量统计；配置迁移 | 统计是只读子视图，不与控制项混排；配置迁移清楚标明是否覆盖 Token、本机偏好与服务设置 |
| 通知 | 后台命令完成、AI 任务完成；权限/系统限制状态和测试通知入口 | 区分用户关闭、系统阻止和不支持；测试入口只在用户点击时发送 |
| 关于 / 更新 / 帮助 | 版本、检查更新、项目资料、引导、更新历史、赞助 | 固定独立入口；完整历史和技术栈按需查看，不参与日常设置长列表 |

安全工作区继续承担运行状态、目录实体管理、文件历史还原等任务。初期保留“查看/管理”跳转；如果后续嵌入策略表单，必须共用同一组件和状态源，不复制一套独立保存逻辑。

## 6. 视觉与控件规范

### 6.1 布局和层级

- 页面结构固定为：分类标题 → 一句用途说明 → 分组 → 设置行 → 行内状态。主要控件直接可见。
- 设置行统一标签和控制列；大窗口采用约 960–1120px 的主要工作区，剩余空间可放预览或关联说明。避免将短标签与开关拉到窗口两端。
- 常规行高约 56–64px，纯单行可更紧凑；有说明时自然增高。组间间距 20–24px，组内 12–16px。
- 窄窗口改为标签上、控件下；长路径、错误、选项列表自然换行，不依赖横向滚动。
- 大类页面只用一层主要阅读容器；内部靠留白和弱分隔分组，减少嵌套玻璃卡与整圈白边。

### 6.2 字体与颜色

- 页面标题 18–20px，分组标题 15–16px，设置标签约 14px，说明/控件文字约 12–13px；关键操作和当前值不使用 11px 小字。
- 正文使用统一系统 UI 字体；路径、端口、命令及终端示例使用等宽字体。
- 主色用于当前选中项、主要操作、键盘焦点；成功、警告、错误使用语义色，普通“关闭”不是错误。
- 柔光保留在背景和一级容器，输入与阅读区更稳定、更不透明；经典只替换材质，不另做一套布局。
- 当前指针、键盘焦点和已选中状态分别设计，不能用同一个紫色外圈表达三种状态。

### 6.3 控件选择

| 类型 | 统一规范 |
|---|---|
| 布尔偏好 | 开关 + 可见名称 + 必要影响说明；提供读取、保存中、错误、禁用原因状态 |
| 2–4 个短互斥选项 | 分段单选器；语义使用单选组及选中状态，不与动作按钮混用 |
| 外观与字体 | 有真实示例的预览卡；沿用已确认的浅紫底、柔和外圈、右上角实心勾规范 |
| 多选工具或能力 | 复选框列表 + 已允许数量，必要时搜索；总开关关闭时明确当前不生效 |
| 长列表 | 下拉选择；选项多时支持搜索，禁用项说明原因。现有短列表不为统一而全部改下拉 |
| 数字与单位 | 输入框 + 清楚单位/范围；允许清空再输入；错误行内呈现，不在输入过程中反复强制回填 |
| 动作 | 主/次/危险三级按钮；复制、检测、导入、清理不是开关，也不是选中胶囊 |
| 帮助 | 常显后果和生效条件，原理进详情；危险影响不能只藏在问号或悬停说明里 |

## 7. 交互与反馈规范

| 情况 | 推荐方式 | 反馈与恢复 |
|---|---|---|
| 普通本机偏好 | 即时应用 | 行内“已应用/已保存”；无法持久化时明确“本次生效，未能记住” |
| 后端开关 | 请求期间锁定当前项或对同项请求串行化 | 成功后更新已确认值；失败恢复原值，错误留在该行并可重试 |
| 数字及组合策略 | 草稿值 + 明确应用 | 展示当前生效值与未应用状态，离开时提示保留/放弃草稿 |
| 端口、TLS、封禁策略等影响运行的修改 | 校验 → 说明影响 → 保存 → 必要时重启 → 核对生效 | 失败停在实际失败步骤；区分“配置已保存但重启失败”与“保存失败” |
| SSE 等涉及远端迁移的切换 | 展示迁移命令及操作顺序，确认后等待结果 | 复制迁移命令不等于迁移完成，切换成功不能提前播报 |
| 日志清理、缩短保留期、配置覆盖、权限扩大 | 显式确认，说明对象、范围与影响 | 条件允许时提供影响预览；普通偏好不弹同级确认 |
| 自动读取失败 | 保持未知/加载失败，提供重试 | 不能把读取失败显示成关闭或默认值已确认 |

预览方案：

- 应用外观：两张同一真实页面缩略图比较经典与柔光，明暗另作单独维度。
- 终端：独立、无 SSH 连接的真实终端示例，包含路径、提示符、中文、日志和状态栏；配色/字体/字号共用一个预览。
- 实际终端偏好继续明确“即时生效/需要新开会话/需要重启远端程序”，预览不能伪装已经生效。
- 对减少动态效果使用静态状态变化；行内反馈不推动整页跳动。

## 8. 一致性、搜索与可访问性

1. 扩展共享设置行契约：稳定 `id`、标签、说明、错误、保存状态、生效条件、范围和重置入口；本地偏好与后端设置使用不同保存适配器，共用展示规范。
2. 设置注册表先集中导航、标题、关键词、锚点、生效方式；不在第一阶段制造可配置任意表单的通用引擎。
3. 搜索覆盖具体设置名称及同义词，例如字号/字体大小、回滚/历史、GBK/乱码；结果直达控件，显示分类路径，处理条件隐藏项并说明前置条件。
4. 保留旧命令面板和安全工作区深链接，使用旧锚点到新分类/控件的映射。
5. 所有输入建立 label 关联，说明/错误通过 `aria-describedby` 关联；单选组正确表达选中项，开关正确表达开关与禁用状态。
6. 完整键盘操作：Tab、Space、Enter、方向键、Esc；浮层关闭后返回触发控件，错误不自动抢走当前编辑焦点。
7. 普通文本对比度以 4.5:1 为最低验收基线，大字和关键非文本信息按对应标准测量。柔光需测合成后的实际背景，不只测 token。
8. 桌面控件建议高 32–36px；图标按钮建议约 32px 点击范围，触摸场景尽量 44px。WCAG 2.2 AA 的最小目标通常为 24×24 CSS px，存在规定的间距等例外，不能把 44px 误称为所有场景的 AA 门槛。
9. 保存中用恰当 busy 状态；成功用克制的 polite 播报，错误保持可读可重试。不能只靠颜色、抖动或消失很快的 Toast 表达结果。
10. 导入/导出清楚区分服务配置、本机偏好和凭据；新增迁移范围时保持旧配置文件兼容。

## 9. 分阶段实施与验收

| 阶段 | 优先级 | 交付物 | 验收重点 |
|---|---|---|---|
| 0. 操作正确性 | P0/P1 | 审计策略显式应用；TLS/SSE 正确等待结果；读取失败、逐项 pending/错误状态 | 保存失败绝不提示成功或继续不应执行的动作；清理影响明确；请求乱序与失败回归通过 |
| 1. 分类与导航 | P1 | 七分类骨架、精确检索、旧锚点映射、分类状态记忆 | 不再跨全部设置长滚动；字号/编码/自启可直达；不丢草稿；安全工作区入口保留 |
| 2. 视觉与控件统一 | P1/P2 | 设置行、开关、单选器、预览卡、数字输入、错误/禁用规范；深浅色和两种材质适配 | 主要操作可见、选中与焦点可区分、输入标签完整；宽窄布局与长文案稳定 |
| 3. 预览与管理细节 | P2/P3 | 应用/终端示例、MCP 服务列表摘要、用量子视图、迁移范围说明、关于详情 | 预览不执行真实远程命令；权限生效范围清晰；恢复/迁移说明与实际覆盖范围一致 |

实施顺序建议：先做应用与终端两页样板，确认视觉及控件规范，再推广到网络、文件命令、数据与 MCP。涉及删除、覆盖或服务重启的正确性修复可独立先行，不等待整套视觉完成。

每阶段同时补齐对应交互测试和可访问性检查，不将无障碍留到最后补救。暂不改变端口默认值、权限默认值、已保存的用户偏好及配置格式。

## 10. 最终验收清单

- 常用设置通过明确分类或一次检索直达，结果定位到控件而不是整张卡。
- 读取失败、保存失败、重启失败、本次生效但持久化失败均有不同反馈。
- 审计策略不会在用户只输入/失焦时悄悄触发删除。
- 缩短保留期、导入覆盖及扩大权限均在执行前说明影响，已有确认流程保留。
- 深浅色 × 经典/柔光、560px/常规/宽窗口、系统缩放与长文案覆盖；所有条件区展开后检查溢出。
- 仅用键盘完成切分类、搜索字号、改普通偏好和取消高风险操作；完整读屏、对比度及触摸验证单独记录结果。
- 切类别和主题保持草稿、滚动位置和终端会话；新增预览不连接真实 SSH。
- 已有配置读取兼容、旧锚点兼容；不引入重复设置源。
- 用真实任务测试评估定位速度和误操作率，不在未测试前声称固定百分比改善。
