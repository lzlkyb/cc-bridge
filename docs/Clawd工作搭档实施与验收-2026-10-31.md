# Clawd 工作搭档：实施与验收

2026-10-31，按已确认的圆润矢量交互稿接入正式对话页。三个阶段在同一实现内交付。没有改动工作区原有的终端／文件管理开发内容，没有打包发布或替换已安装应用。

## 页面行为

- 回复标题以静态 Clawd 头像替代星芒和可见的 Claude 字样，保留模型名和屏幕阅读器身份说明。
- 当前工作区只有一个主角色；使用真实工具、思考、审批、重试与结束事件选择姿势。等待摆脚，读取看书，编辑敲键盘，执行面向终端，审批举手，完成轻跳一次。不是定时随机切状态。
- 主角色在当前消息／工具／审批旁与输入框上方之间移动。目标预留空间；目标不在阅读视口时停靠底部，不自动滚回、不占据历史正文。点击可展开真实工具内容或定位审批入口，空闲点击挥手；输入时保持安静。
- 支持经典／玻璃、明／暗外观，窄窗口重排。系统减少动态效果即时生效，也可手动保存偏好。隐藏页面与不可见会话暂停动作，历史头像不播放循环动画。
- 小队只展示具备 Agent 类型或明确子 Agent 名称的任务，普通后台命令不冒充成员。可展开成员、查看独立状态、父任务、最近工具、原始任务摘要并定位原始调用；超过四个成员可进一步展开。
- 失败与停止不显示成功；命令完成不宣称测试通过。停止未确认有单独文字状态，审批直接使用既有真实权限卡片，不增加一套放行通道。

## 运行数据与恢复

后端新增归一化 `taskUpdate` 与 `taskSnapshot` 事件，接收 CLI 的 `task_started`、`task_progress`、`task_updated`、`task_notification` 和完整后台任务集合。保留 task ID、run ID、父任务、来源工具、任务类型、子 Agent 名称、局部更新和实际摘要。

同一 reducer 同时处理实时与重放。较旧 run 不覆盖新 run；同一 run 的重复启动不把已完成任务复活。后台快照中消失的任务只标记状态未知，不猜测完成；前台 Agent 不受后台集合移除影响。正常轮结束不擅自结束后台 Agent。进程退出或重启使未确认任务变为未知；主动停止使用停止状态。

从历史数据库载入与实时内存快照明确区分：历史中的运行记录不是当前存活证据，不恢复后台忙碌指示；实时快照可保留仍存活的后台任务。旧版 CLI 若只有数量，显示后台数量与等待提示，不编造成具体成员。

事件依据：[Claude Code Agent SDK TypeScript reference](https://code.claude.com/docs/en/agent-sdk/typescript)，尤其 `SDKTaskStartedMessage`、`SDKTaskProgressMessage`、`SDKTaskUpdatedMessage`、`SDKTaskNotificationMessage` 与 `SDKBackgroundTasksChangedMessage`。具体事件可用性取决于所用 CLI 版本；没有收到的字段不补造。

- 主工作区、小队、定位：`ClawdWorkspace.tsx`、`ClawdTeam.tsx`、`desktop/src/hooks/useClawdMotion.ts`。
- 状态推导与任务合并：`desktop/src/lib/ccClawd.ts`、`ccAgentTasks.ts`、`ccReducer.ts`。
- 协议：`desktop/src-tauri/src/cc_session/tasks.rs`、`proto.rs`。

按照用户的 `code-review` 工作流检查安全、正确性、可访问性和回归，并运行只读 `codex review`，限定本次文件、排除原有终端改动。审查发现的同 run 重复启动复活问题已修复并加入回归断言。关于 run ID 不可排序的建议未采纳：官方文档明确允许同一任务的 run ID 按字符串判断先后，代码已附依据。

页面回归还修复了两个直接相关的问题：新增停止入口的无障碍名称与原输入区区分；明确的搜索／记录定位会暂时解除自动贴底，避免展开过渡把阅读位置拉走。

- 前端完整测试：158 个测试文件、1585 项通过；新增状态、任务回放与组件交互测试包含历史恢复、重复启动、独立成员、审批定位、动作偏好和点击行为。
- 会话后端测试：`cargo test --no-default-features --lib cc_session:: -- --test-threads=2`，173 项通过，包含完整生命周期归一化和新事件序列化往返。
- `npm run lint`、TypeScript 检查、Vite 生产构建、组件体量门禁通过。构建仍有已有的大 chunk 提示；未为此扩大修改范围。
- Clawd 浏览器验收：9 组通过，报告与截图为 `.impeccable/review/clawd-production/report.json`。覆盖正式组件与实际 reducer 路径、工具定位、真实成员事件、明暗外观、减少动作及 560／390px 审批布局。
- 原有对话页完整回归：最终 25/25 通过，报告为 `.impeccable/review/clawd-regression-final/report.json`；包含发送、队列、停止、搜索、工具展开、长会话阅读、审批、快捷键和各外观截图。最终报告无浏览器运行异常或外部请求。
- 机械界面检查对新增角色／工作区／小队／样式返回空告警；最终 diff 无空白错误。

浏览器使用正式组件加模拟 IPC 事件，不是实时模型、SSH 或已安装原生包的端到端验收。没有调用付费模型、修改远端配置、安装应用或发布版本。角色为本项目内嵌曲线矢量重绘，不需要网络素材。
