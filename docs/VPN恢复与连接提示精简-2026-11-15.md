# VPN 恢复与连接提示精简

日期：2026-11-15。版本保持 3.1.5。

## 问题与本轮修改

VPN 中断后，“固定端口 7823 无法监听”可能一直留在页面。代码检查与回归用例确认，后台重连和页面状态都有问题：

1. SSH 已认证但远端监听失败时，原后台进程可能继续驻留，不再申请端口。Claude Code 托管隧道现在使用 `ExitOnForwardFailure=yes`，退出后由原监管线程重试；仅认证成功不重置退避，真正监听成功才重置。手动混合转发继续保留成功规则。
2. 恢复已有接入原先经过有时间上限的配置流程，等待失败后会停止隧道。恢复原配置现在直接交给长期监管，保留原固定端口、MCP 名称、范围、目录及已有验证时间，持续尝试原地址，不重新写入远端配置。
3. 已结束的连接阶段错误原先会覆盖后来恢复的运行状态。未改配置的旧连接错误现在以实时监管状态为准；配置写入失败与进行中的操作仍显示各自结果。
4. 后台可能漏读同一块输出中已经换行的登录提示。现在在清空行前处理，完整行和分段输出共用一次性填写保护；Windows 使用终端回车提交凭据。登录密码、密钥口令分别填写，改密、验证码等交互提示继续停止并交还用户处理。
5. 托管 SSH 握手现在限制为 10 秒，避免网络中断时长时间停在一次尝试并超过 30 秒自动填写窗口。SSH 退出前没有换行的最后一段输出也会被解析；托管监听失败优先显示对应端口的原因，旧密码提示不作为退出原因。

网络恢复和端口释放后，后台继续沿用 `http://127.0.0.1:7823/mcp`。重连从 2 秒递增，最长间隔 60 秒；恢复时间还取决于服务器释放旧监听及网络状态。需要重新登录或用户主动暂停时，界面显示相应状态，不宣称已连接。

临时登录信息仍只用于本次应用运行期间的连接与重连，不自动保存。退出或开发窗口重启后，未保存的登录信息需要在原接入卡重新填写。

本机自带的 OpenSSH 8.1 会独占 `-E` 日志文件，不能用持续文件读取来确认运行状态。本轮试验中发现该方式会阻止 SSH 启动，已移除新增的文件日志通道；最终实现继续从原终端输出读取状态与退出原因。

## 已精简的提示

`CurrentConnectionAlert` 不再为连接异常或自动重连渲染跨页横幅，内容区不留空位。顶栏继续显示“正在重连”“需要重新登录”等全局状态，点击可定位原接入卡。

本机收到失效令牌访问属于独立事件，本轮保留该提醒。

## 后续精简规划

以下为规划，本轮未扩展修改这些入口。原则：顶栏显示全局状态，接入卡集中说明原因与处理动作。

| 位置 | 当前重复 | 建议 |
| --- | --- | --- |
| 侧栏左下角 | 与顶栏重复“正在重连”“连接异常” | 删除连接状态胶囊；更新和设置入口继续独立显示。 |
| 连接看板 | 与接入卡重复长故障段落和恢复说明 | 保留本机服务、隧道通道、接入验证的链路简况；故障原因与处理说明只放原接入卡。 |
| 接入卡状态行 | “处理连接问题／查看连接状态”与“管理”在部分状态都展开同一表单 | 按状态提供一个主要动作：重连中查看详情、缺凭据重新登录、暂停恢复隧道、配置变化应用配置。管理放入次要菜单。 |
| 端口转发面板 | 托管状态的故障详情与原接入卡重复 | 保留自动管理、简短运行状态、固定端口与管理接入入口；故障详情统一定位原接入卡。 |
| 全屏终端、托盘、命令面板 | 同一状态出现在不同使用场景 | 保留简短状态及定位入口，共用状态来源，不增加同类故障横幅。 |

同一接入卡也应只展示一次主要错误说明。详细原始输出按需展开，表单输入错误靠近对应字段；本机服务故障与失效令牌访问各自有处理目标，不能仅因同时出现就合并成隧道错误。

## 回归验收

| 场景 | 应有结果 |
| --- | --- |
| VPN 中断后重新连接 | 托管隧道继续尝试原端口，监听成功后恢复运行；无需改 MCP 地址。 |
| 旧远端监听暂未释放 | 显示正在自动重连，持续退避；不自动换端口、不强制清理未知进程。 |
| 恢复已保存接入 | 不再被一次配置等待超时停止，保留原接入身份和配置。 |
| 旧连接错误之后监听成功 | 顶栏、接入卡、托管面板按当前状态更新，旧错误不覆盖成功结果。 |
| 缺少登录凭据 | 明确提示需要重新登录，不无限尝试同一个无效登录。 |
| 带换行或分段登录提示 | 有凭据时填写并提交一次，无凭据时停止等待用户登录。 |
| 网络中断造成握手挂起 | 单次握手在 10 秒上限内退出并进入重试，避免耗尽 30 秒自动填写窗口。 |
| 退出错误没有换行、旧密码提示仍在输出中 | 解析真实退出错误；托管监听失败优先显示端口原因，不把旧密码提示当作退出原因。 |
| 手动混合规则 | 一条监听失败不停止其他成功规则，托管规则仍不重复开启。 |
| 取消、SSH 或服务配置变化 | 不启用已取消或过期的恢复请求，用户暂停状态保持。 |
| 终端与其他页面异常状态 | 顶栏有状态，原重复横幅及其占位消失。 |
