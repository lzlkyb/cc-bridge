# 连接页柔光层级与轻惯性验收

用户选择雾蓝淡紫玻璃后，进一步要求保留服务卡的视觉主次，并确认采用轻惯性、利落缓停。

## 实施

- 正常/停止服务采用同系玻璃阅读面，主卡比指标卡深一档，运行状态标题为 16px。警告、启动错误保持原有醒目语义。停止服务和重启为次级动作，启动服务保留主色。
- 服务链路、地址条、最近活动适配深浅阅读面。工具分段器只抬起当前选项；地址与接入模式共用浅紫底色、柔和外圈及右上角实心勾，可达性徽章在地址信息行独立展示。
- 基础防护配置齐全不再表述为整体安全推荐。只读关闭及普通配置不显示绿色防护勾；命令执行开启保留风险色。
- 无调用数据、采样不足、真实零值、已有非零历史分别展示；静止命令不再使用警告色。
- 普通可滚内容区的粗粒度滚轮采用 160ms 缓停，反向输入取消旧方向余量。滑块拖动、按键、触摸及内容定位可中断；终端、输入控件和菜单保持原生滚轮处理。
- 精细像素输入识别为原生输入流，直到该流停止后才重新启用粗粒度缓停。WheelEvent 不提供可靠设备身份，采用输入特征识别，避免叠加精细输入流的系统惯性。
- 系统减少动态效果、窗口隐藏、节点隐藏/卸载时停止惯性，无常驻动画帧。

## 验证

- 全量 843 项测试通过；其中本轮新增 12 项状态/图表回归测试与 20 项惯性回归测试。
- ESLint、TypeScript、前端构建、组件体量门禁和 diff 检查通过。构建保留既有的大分块提示。
- 真实组件预览覆盖深浅色、经典材质、560px 最小窗口、工具/IP 选择和实际滚轮操作。
- 辅助显示夹具覆盖深浅色、减少透明度及强制颜色下的 CSS 层叠；启动按钮主色与正常阅读面回退通过。这是媒体规则夹具，不等同于切换操作系统主题。
- 两次静态代码审查发现的启动按钮优先级和精细滚动流超时问题均已修复；后者补充连续输入回归断言。
