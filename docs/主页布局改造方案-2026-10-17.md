## 一、目标与素材现状

以设计预览 A 稿为准，把正式应用的「外壳（侧栏 + 顶栏）+ 连接页」对齐到稿中布局。

有利条件：预览稿**不是画出来的**——它复用了生产组件与纯函数（`Icon`、`computeChain()`、`buildClientSnippet()`、`CLIENT_LABELS`），链路口径与正式应用一致，结构与样式可直接迁移。

不利条件：稿中「Token 用量近 7 天柱状图」「最近活动 3 条」是**写死的示例数据**（`main.tsx` 顶部 `days` / `activities` 常量），正式版必须有真实数据源或降级。

## 三、决策点（需用户拍板）

### D1 服务启停/重启放哪
- **稿**：顶栏没有启停，重启/停止都在连接页服务面板。
- **现状**：顶栏启停是全局入口（安全页、日志页也能一手停服）。
- **推荐 a**：顶栏保留启停不变；服务面板内**新增「重启」**（后端 `restart_mcp_server` 命令已存在，`commands.rs` 已注册）+ 停止按钮。两处并存，全局可达性不丢。
- 备选 b：完全按稿移走。代价：异常处置多一次跳转。

### D2 面包屑是否回归
- 之前删的是「< 连接」——读作「返回到连接」的误导语义；稿里的「工作区 / 连接」是**层级位置**语义，两者不同，不构成翻烧饼。
- **推荐采纳**：`工作区 / {当前页名}`，页名取 `WORKSPACE_NAV` label（含设置页显示「工作区 / 设置」）。零风险小改动。

### D3 侧栏底部状态是否常驻
- 稿：常驻绿点「本机服务运行中」；现状（E 方案）：异常才现，理由是「绿点脉冲是常驻壁纸、零信息增量」。
- **推荐折中**：常驻**静态**绿点行（不脉冲、不可点、零动画成本），异常时原样变形为橙/红可点胶囊（现有 `status-pill` 逻辑直接挂上去）。气质拿到手，噪音可控。备选：维持异常才现。

### D4 假数据卡片的真源
- 「Token 用量近 7 天柱状图」目前**没有真实数据源**（后端无按天聚合）。选项：
  - a) 该卡改用现有真源指标（如今日调用数 / 累计请求），不画 7 天柱状图；
  - b) 保留用量卡现状（UsageCard 已有内容）仅换外壳排版，**不做** 7 天图；
  - c) 后端加按天聚合（超出本轮布局改造范围，不建议同批做）。
- **推荐 b**：本轮只动布局，不动数据口径。

## 四、实施批次（确认后执行）

### 批 1 外壳（SideNav / Header / index.css）
- 品牌卡（含 tagline）、导航 kbd 徽标、workspace-note、底部状态行（按 D3）。
- 面包屑（按 D2）、「搜索命令 Ctrl K」文字版按钮。
- 折叠态（56px 图标栏）：tagline / kbd / note 全部收起，沿用 `data-collapsed` 既有机制。
- 体量注意：SideNav 现 209 行，新增块建议把 workspace-note + 状态行拆成子组件（300 行棘轮）。

### 批 2 连接页重构（ConnectTab / ConnectBento → 纵向分区）
- 页头 heading → service-panel → 接入面板 → 运行概览 → bottom-grid（健康+用量）→ 最近活动 → 页脚（可选）。
- `StatusCard` 拆分重排：summary 与链路迁入全宽 service-panel；**ServiceChain 配色重写**——现在是深色渐变卡上的 white/透明度（`index.css` E2 区），浅底上必须回归语义 token（小字标签用 `-ink` 变体，对比度按「文字 vs 淡底叠卡片底」算）。
- 接入面板：套稿的外壳（收起/展开 + tabs + code-block 样式），ConnectGuide 的 scope/步骤/token/权限内容**全保留**。
- ConnectTab 现 177 行，service-panel 独立成组件，防棘轮超标。

### 批 3 清理
- `.bento` 12 列 CSS 子选择器、StatusCard 深色渐变退役；preview.css 样式按 token 语义化并入 index.css。
- 连接页 `@container` 断点复核：820px 边界是按 12 列 Bento 算的，纵向布局后需重新实测（CDP 探针量取回填）。

每批独立 commit，跑全前端四项门禁（check-component-size → eslint → tsc → vitest）。

## 五、约束与风险

- 🔴 容器查询只能挂 `TabsContent`，不挂 `<main>`（全屏终端态 containment 问题）。
- 🔴 顶栏恒 52px / 字形带约束：面包屑在左段、UpdateReadout 仍住中段 `flex-1` 拖拽区，互不挤压；不新增任何贴顶浮层。
- 🔴 折叠态全回归：1080px 阈值、`data-collapsed` 两态截图取证（R4：先出稿——本轮稿已有，实施后拿真窗口截图对比）。
- 面包屑出现在所有工作区页（连接/终端/安全/日志），终端全屏态下顶栏本来被盖住，无冲突。
- 重启不做二次确认框（R17）。

## 六、明确不做

- 「示例数据 · 未连接真实服务」标签、预览 toast 演示逻辑（仅预览环境）。
- 7 天 Token 柱状图的后端聚合（D4-c 另立项）。
- 终端 / 安全 / 日志 / 设置页的视觉精修（稿中 toast 已注明「下一轮」）。
