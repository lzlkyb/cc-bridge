# 软件更新弹框品牌玻璃改造验收

## 范围与行为

- 按已确认 v2 设计接入正式组件：品牌双栏、海豚图标、大目标版本号（桌面 58px、窄窗口 48px）；长版本号单独缩小并换行。
- 使用真实后端版本和更新说明，首屏最多精选三项亮点，折叠说明仍保留全部亮点及跨版本记录；不直接执行远端 HTML。
- 深浅色与毛玻璃、经典外观分别适配；短窗口内内容滚动，操作区固定可见。减少动态效果偏好下停用局部动画。
- 下载、校验安装、待重启、错误反馈共用同一弹框。关闭下载弹框不取消后台更新；侧栏徽章、折叠状态点和关于页可以重新打开进度。
- “稍后提醒”仅关闭，“忽略此版本”记住版本并抑制后续主动提示。显式点击更新入口仍会先展示详情。

## 安装流程约束

按用户 2026-11-01 补充要求，**保留下载结束后自动启动安装器**；`commands/update.rs` 与本次修改前一致，不缓存下载包等待第二次确认。

Windows NSIS 安装会退出当前软件，由安装器继续执行；界面提前提示保存工作。浏览器验收不会真实下载或安装，因此未端到端执行 NSIS 安装。

在安装成功后仍需应用内重启的平台，移除 8 秒自动倒计时，改为确认重启。任务检查读取全部活跃对话、后台任务、后台命令、SFTP 传输；空闲 CLI 进程与空闲 SSH 连接不会被算成运行任务。无法读取任务状态时不启动应用内重启，确认及过渡结束后均重新检查。普通终端内部命令无法精确判断，因此始终提醒重启会关闭终端连接。
