# 关于页三处高饱和元素在毛玻璃主题下的适配方案

日期：2026-11-03 · 状态：**方案 B 已实施**，待真机核验（见 §九）
关联：`design/2026-11-03-about-glass/preview.html`（设计稿）、`appearance.css`（玻璃材质总源）

## 一、问题

毛玻璃主题（`html[data-ui-style="glass"]`）下，关于页有三处被标红：

| # | 位置 | 现状实现 |
|---|---|---|
| ① | 标题「关于 CC Bridge」旁的版本胶囊 `v3.1.1` | `AboutGroup.tsx:115-120`，内联 `background: var(--version-gradient)` + `box-shadow: 0 2px 6px var(--version-shadow)`，文字 `text-white` |
| ② | 更新历史那行的 `v3.1.1` 胶囊 + 右端「最新」tag | `ChangelogView.tsx:32-52`，胶囊与 tag 是 `--color-primary`（#4F46E5）实底 + 白字；条底是 `--color-accent`（#EEF2FF）不透明底 |
| ③ | 本次更新亮点条 | `ChangelogView.tsx:56-66` + `index.css:1375-1378`：`linear-gradient(135deg,#6366F1,#8B5CF6)` 实底 + `0 2px 8px rgba(99,102,241,.25)`，正文与图标写死 `text-white` |

用户判断是"显示不友好"，没有说哪里不对。下面把它拆成三条可核对的原因。

## 二、根因

### 1. 材质断层（主因，视觉）

玻璃主题下卡片是 `--glass-reading`：白 84%→72% 的半透明渐变，配 `--glass-edge`（白 20%）描边与 `--glass-depth`（内侧 1px 高光 + 1px/6px 两档极短外投影）。这套语言贯穿全站。

上面三处仍是 classic 的不透明高饱和实底，投影是 `0 2px 6px rgba(79,70,229,.32)` —— 方向朝下、色相饱和、柔度低。结果：

- 投影颜色与卡片底（冷白）不同族，看起来像"从另一层飘出来"；
- 半透明层里出现 100% 不透明色块，材质感被单点打断；
- 亮点条是全宽多行块，面积最大，成为整屏最重的视觉元素，压过了页面主体信息。

### 2. 同类缺陷在顶栏已经修过一轮，关于页漏了

`appearance.css:259-317` 把顶栏 `.header-badge` 整组改成了玻璃面板：`--glass-panel` 底 + `inset` 顶部高光 + `inset` 下沿描边 + 1px 外投影，注释写着 *"Update badges share the connection cards' material, scaled to a stable sidebar slot."* 深色档单独一套（`appearance.css:280-310`）。

关于页这三处是同形态元素，没跟着改。这是遗漏，不是设计选择。

### 3. 对比度确有两处不达标（实算）

按 WCAG 2.1 相对亮度计算，玻璃卡底取 `--glass-reading` 叠 `--glass-canvas` 的合成值（浅色 ≈ `#F7FAFE`）：

| 元素 | 现状 | 对比度 | 判定 |
|---|---|---|---|
| ① 版本胶囊 | 白字 on `#6366F1`（渐变左端） | **4.47:1** | 差 0.03，不达 AA 小字 4.5 |
| ② 版本胶囊 / 最新 tag | 白字 on `#4F46E5` | 6.29:1 | 通过 |
| ③ 亮点条正文 | 白字 on `#8B5CF6`（渐变右端） | **4.23:1** | 不达标 |
| ③ 亮点条正文（深色玻璃） | 白字 on `#5B54E8` | 5.4:1 | 勉强 |

⚠️ **这两处对比度缺陷 classic 主题同样存在**（同 token、同写法），只是 classic 下"实底配白字"看起来合理，没人报。修与不修要单独决定，见 §六。

## 三、三个方向

| | 方案 A 压深保实底 | 方案 B 材质化 | 方案 C 降级为文本 |
|---|---|---|---|
| 做法 | 渐变压深到 `#4F46E5→#4338CA`，投影换 1px 内高光 + 极短外投影 | 三处换成染色玻璃面板：淡靛半透明底 + `inset` 高光 + `inset` 描边 + 1px 投影；文字改深靛；亮点条收到 10% 染度 | 版本号降为标题后的副标题文本；亮点条去掉底色，只留 2px 左侧强调条 |
| 对比度 | 6.29 / ~7.0，达标 | 7.38 / 8.28，达标 | 11:1 左右，最高 |
| 玻璃协调 | 差（仍是全页最重色块） | 好（与卡片同一材质语言） | 最好（玻璃上零色块） |
| 改动量 | 最小（改 2 个颜色值） | 中（组件加 1 个类名 + CSS 变量回退，`appearance.css` 约 40 行） | 大（classic 与 glass 两套结构） |
| 主要代价 | 没解决"贴纸感" | 「最新」强调感略降（靠描边维持） | 版本号失去可识别的产品标识；双结构维护 |

**推荐 B**。理由：玻璃主题的原则在 `appearance.css:323-331` 里已经写明——"阅读面留白、实体感只给少数几处"。关于页是长时停留的阅读面，亮点条这种整行色块属于该被降级的东西；而版本号仍需要一个"看得见的标识"，所以不适合走 C 的纯文本。

## 四、方案 B 的取值

### 浅色玻璃

```css
html[data-ui-style="glass"] {
  --version-chip-bg: linear-gradient(145deg, rgb(233 237 255 / .92), rgb(219 226 252 / .82));
  --version-chip-shadow: inset 0 1px 0 rgb(255 255 255 / .72),
                         inset 0 0 0 1px rgb(99 102 241 / .16),
                         0 1px 2px rgb(45 61 101 / .10);
  --version-chip-ink: #3B3FA8;
  --cl-bar-bg: linear-gradient(145deg, rgb(240 243 255 / .66), rgb(234 237 252 / .48));
  --cl-capsule-bg: linear-gradient(145deg, rgb(233 237 255 / .92), rgb(219 226 252 / .82));
}

/* 版本条：从"不透明淡靛条"变成"玻璃上的一层薄染" */
html[data-ui-style="glass"] .cl-version-bar {
  background: var(--cl-bar-bg);
  box-shadow: inset 0 0 0 1px rgb(99 102 241 / .10), inset 0 1px 0 rgb(255 255 255 / .55);
}
html[data-ui-style="glass"] :is(.cl-version-capsule, .cl-latest-tag) {
  background: var(--cl-capsule-bg);
  color: var(--version-chip-ink);
  box-shadow: inset 0 0 0 1px rgb(99 102 241 / .16);
}
/* 「最新」是唯一需要被读到的标记，单独加深一档描边与底 */
html[data-ui-style="glass"] .cl-latest-tag {
  background: linear-gradient(145deg, rgb(216 223 252 / .96), rgb(200 210 249 / .92));
  box-shadow: inset 0 0 0 1px rgb(99 102 241 / .34);
}
/* 亮点条：实底渐变 → 10% 染度 + 内描边，文字改深靛 */
html[data-ui-style="glass"] .cl-highlight-bar {
  background: linear-gradient(135deg, rgb(99 102 241 / .10), rgb(139 92 246 / .07));
  box-shadow: inset 0 0 0 1px rgb(99 102 241 / .14), inset 0 1px 0 rgb(255 255 255 / .50);
}
html[data-ui-style="glass"] .cl-highlight-bar :is(li, svg) { color: #333A8F; }
```

### 尺寸不变

设计稿实测（880px 卡片宽度下）：版本胶囊 `53.9 × 20.5px`，版本条 `36.5px` 高，亮点条 `87px` 高。方案 B 只改背景/阴影/文字色，不碰 padding、字号、圆角 ⇒ 上表尺寸不变，核验脚本已断言"几何逐项相等"。

**为什么用 CSS 变量回退而不是 `!important`**：三处底色写在 React 内联 style 上，内联声明优先级高于任何选择器（含 `html[data-ui-style]` 前缀）。变量回退是唯一"classic 读不到、glass 能覆盖、又不用 `!important`"的写法；同时组件里不留条件分支。

**classic 零变化**：所有覆盖都挂在 `html[data-ui-style="glass"]` 下，classic 主题不匹配任何一条；组件侧的 fallback 值就是当前值，逐像素等同。

### 级联为什么成立（不靠猜）

`main.tsx:8,11` 先 `import "./index.css"` 后 `import "./appearance.css"`：Tailwind v4 的工具类都在 `@layer utilities` 里，而 `appearance.css` 是**未分层**样式 —— 未分层规则一律压过分层规则，与选择器权重无关。所以 `html[data-ui-style="glass"] .cl-highlight-bar li` 能盖掉 `text-white`，`html[data-ui-style="glass"] .version-chip` 能盖掉同类写法。顶栏 `.header-badge` 的既有覆盖就是同一条路径，已经跑在生产里。

| glass 浅色 | `rgb(51,58,143)` ✓ | `rgb(59,63,168)` ✓ | `inset` 白 72% + `inset` 描边 16% + 1px `rgb(45,61,101,.1)` |
| glass 深色 | `rgb(207,214,251)` ✓ | `rgb(199,210,254)` ✓ | `inset` 白 16% + `inset` 描边 14% + 1px 黑 18% |
